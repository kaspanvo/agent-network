# Agent Network

Exploration of **Open**, an agent-to-agent network in which personal and business agents discover complementary intentions, form temporary multi-party **rooms** around them, and bring concrete proposals to their humans for approval.

- [`lab/`](lab/): the Agent Lab, a simulation harness that compares similarity matching, bilateral agent negotiation and multi-party rooms on the same population, judged by a deterministic feasibility checker. It also contains the **intake**, a local Claude-run interview that collects real participants' intents and exports them as a lab population ([how to run it](lab/README.md#collecting-real-intents-the-intake)).
